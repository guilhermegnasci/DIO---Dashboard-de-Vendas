# Criando um Dashboard de Vendas do Xbox com Excel

Projeto desenvolvido como parte do desafio de projeto da **DIO (Digital Innovation One)**, no bootcamp **Santander | Excel com IA e Claude**.

## Sobre o projeto

O desafio teve como objetivo desenvolver um **dashboard de vendas do Xbox utilizando o Microsoft Excel**, trabalhando a organização, análise e visualização de dados.

A proposta foi transformar uma base de dados brutos em informações visuais mais claras e úteis, permitindo analisar o desempenho das vendas e facilitar a interpretação dos resultados.

## Objetivo

Criar um dashboard de vendas no Excel capaz de apresentar os principais indicadores da base de dados de forma organizada e visual.

O projeto busca demonstrar a utilização do Excel como ferramenta de análise de dados, utilizando recursos como tabelas, fórmulas, gráficos e elementos de visualização para facilitar a compreensão das informações.

## Dados utilizados

Os dados utilizados foram fornecidos no contexto do desafio da DIO e estão relacionados às vendas de produtos e serviços do ecossistema Xbox.

A base de dados contém informações utilizadas para realizar análises relacionadas às vendas, permitindo a criação dos indicadores e gráficos apresentados no dashboard.

## Ferramentas utilizadas

* **Microsoft Excel**
* **Tabelas e organização de dados**
* **Fórmulas do Excel**
* **Gráficos**
* **Dashboard**
* **Recursos de visualização de dados**
* **Inteligência Artificial** como apoio ao desenvolvimento do projeto

## Desenvolvimento

Para a construção do projeto, os dados foram organizados no Excel e utilizados como base para a criação dos indicadores e visualizações.

O dashboard foi desenvolvido buscando apresentar as informações de maneira simples e objetiva, permitindo uma análise mais rápida dos dados de vendas.

A construção do projeto envolveu as seguintes etapas:

1. Organização da base de dados.
2. Análise das informações disponíveis.
3. Definição dos principais indicadores.
4. Criação das tabelas necessárias para análise.
5. Desenvolvimento dos gráficos.
6. Organização dos elementos visuais.
7. Construção do dashboard final.

## Dashboard

O resultado final é um dashboard desenvolvido no Excel para visualização e análise dos dados de vendas do Xbox.
